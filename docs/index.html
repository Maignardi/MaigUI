Instalação

Disponível via GitHub (JitPack) e Maven Central.

// settings.gradle.kts
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven("https://jitpack.io")
    }
}

// build.gradle.kts (app)
dependencies {
    implementation("com.github.Maignardi.MaigUI:maig-ui:0.1.0")
    implementation("com.github.Maignardi.MaigUI:maig-ui-forms:0.1.0") // opcional
}
// build.gradle.kts (app)
dependencies {
    implementation("io.github.maignardi:maig-ui:0.1.0")
    implementation("io.github.maignardi:maig-ui-forms:0.1.0") // opcional
}

Formulários & Máscaras Brasileiras (maigui-forms)

Teste ao vivo abaixo os algoritmos reais de validação de CPF e e-mail usados na biblioteca.

val form = rememberMaigForm {
    field("email") { required(); email() }
    field("cpf") { required(); cpf() }
}
MaigTextField(field = form["email"], label = "E-mail")
MaigTextField(field = form["cpf"], label = "CPF", visualTransformation = MaigMasks.cpf())
